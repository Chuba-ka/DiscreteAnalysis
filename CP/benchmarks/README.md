# Бенчмарк BWT + MTF + RLE

Из корня проекта:

```bash
python3 benchmarks/run_benchmark.py
python3 create_course_report.py
```

Требуются Python 3, g++, GNU time. Генератор PDF использует системные библиотеки Cairo, Pango, PangoCairo и GObject, а также шрифты Liberation Serif и Liberation Mono, как предоставленный образец отчёта.

Основная программа `main.cpp` не изменяется. Измерительный модуль подключает её классы с переименованием исходной функции `main` только в отдельной сборке бенчмарка.

Измеряются пять типов данных длиной 1000, 5000, 10000, 50000 и 100000 символов. Начальное состояние генератора: `8062026 + длина`. Для восьми операций выполняются калибровка до пакета продолжительностью не менее 20 мс и пять измерительных пакетов. Учитывается время выделения памяти и уничтожения результата. Во время замеров проверяется восстановление исходного текста.

Полная консольная программа дополнительно запускается по три раза в каждом режиме. Настенное время включает GNU time, запуск программы и ввод-вывод. Пиковый RSS измеряется только для дочерней C++ программы в КиБ. Это отдельные показатели, их нельзя приравнивать ко времени вычислений в памяти или размеру рабочих массивов.

Результаты:

- `benchmark_results/stages.csv` — 1000 пакетных отсчётов; время одной операции в миллисекундах.
- `benchmark_results/cli.csv` — 150 отдельных запусков; время в миллисекундах и RSS в КиБ.
- `benchmark_results/results.json` — сводные результаты, сведения о среде, SHA-256 исходного кода и входных строк.
- `Отчет_КП_F_BWT_MTF_RLE.pdf` — отчёт, сформированный из полученных результатов.

Размер сжатых данных — фактические байты текстового вывода с пробелами и переводами строк, без команды режима. Исходный размер не включает перевод строки. Нагрузка ОС и частота процессора не фиксируются; результаты относятся к среде, указанной в JSON и отчёте.

Генератор отчёта сверяет контрольную сумму `main.cpp` с результатами замеров. После изменения решения сначала необходимо повторить бенчмарк.
